# SanquimTech — Sistema de Controle Acadêmico

Este repositório contém o código-fonte e os arquivos relacionados ao desenvolvimento do **SanquimTech**, um sistema web voltado para o controle acadêmico do **Colégio Sanquim**, uma instituição comunitária que oferece cursos preparatórios gratuitos para vestibulares e vestibulinhos.

## 📘 Visão Geral

O **SanquimTech** é uma aplicação web leve, responsiva e de fácil uso, projetada para digitalizar e automatizar os principais processos educacionais da escola. Desenvolvido especialmente para funcionar em contextos com infraestrutura limitada, o sistema pode ser acessado por dispositivos móveis e desktops, sem a necessidade de instalação local.

Entre os principais processos atendidos, destacam-se:

- Matrícula de alunos
- Registro de frequência
- Planejamento e registro de aulas
- Envio de materiais de apoio
- Acompanhamento acadêmico pelos alunos
- Gestão administrativa centralizada

---

## 🎯 Objetivos do Projeto

- **Automatizar** o processo de matrícula e controle acadêmico
- **Organizar** o histórico de aulas e o planejamento docente
- **Facilitar** a comunicação entre coordenação, professores e alunos
- **Reduzir** o uso de papel e o risco de perda de dados
- **Promover** maior acessibilidade à informação e autonomia aos alunos

---

## 🧩 Funcionalidades

- ✅ Cadastro de alunos, professores e turmas
- ✅ Controle de presença com justificativa de faltas
- ✅ Registro e planejamento de aulas
- ✅ Portal do aluno com frequência, aulas e notas
- ✅ Painel administrativo com indicadores e relatórios
- ✅ Envio de materiais de apoio e comunicados
- ✅ Recuperação de senha por e-mail
- ✅ Calendário escolar com eventos, provas e feriados

---

## 📋 Requisitos Funcionais e Não Funcionais (Resumo)

### Funcionais
- Matrícula de alunos
- Registro de aulas e frequência
- Planejamento de aulas
- Painel administrativo
- Portal do aluno
- Envio de comunicados e materiais
- Recuperação de senha
- Emissão de relatórios
- Calendário escolar interativo

### Não Funcionais
- ⏱️ Tempo de resposta: até 3s para ações comuns
- 🔒 Segurança com autenticação por perfil
- 📱 Interface responsiva para desktop e mobile
- 📈 Escalabilidade e modularidade
- 🔧 Código manutenível e bem documentado
- 🔐 Armazenamento seguro de dados sensíveis

## 🛠️ Tecnologias Utilizadas

O projeto será desenvolvido com foco em acessibilidade, desempenho e fácil manutenção, utilizando ferramentas modernas e acessíveis:

- **Front-end:** HTML, CSS, JavaScript
- **Back-end:** PHP via XAMPP
- **Banco de Dados:** MySQL/MariaDB
- **Prototipação:** Figma
- **Controle de Versão:** Git e GitHub
- **Gerenciamento de Projeto:** Trello

> *As tecnologias podem ser ajustadas conforme a evolução do projeto e as decisões do grupo.*
